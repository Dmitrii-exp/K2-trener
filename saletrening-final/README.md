# SaleTrening Final

Готовый frontend-пакет AI-тренажёра продаж.

Подключены:
- Supabase
- сценарии
- тренировочные сессии
- сохранение транскриптов
- результаты
- личный кабинет менеджера
- кабинет руководителя
- команда
- аналитика команды
- рейтинг
- навыки
- админка и конструктор сценариев
- адаптивная верстка
- отдельная точка подключения AI/STT/TTS

AI-модуль намеренно оставлен внешним: после выбора провайдера его можно подключить к существующим сценариям и сессиям.

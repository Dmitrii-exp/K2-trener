# K2-trener

## Назначение

AI-платформа для тренировки сотрудников отдела продаж.

## Основные функции

- Регистрация пользователей
- Роли сотрудников и руководителей
- Голосовые AI-тренировки
- Анализ переговоров
- Оценка сотрудников
- История тренировок
- Статистика
- Конструктор тренировок
- Настройка поведения AI-клиента
- Назначение тренировок сотрудникам

## Роли

- Admin
- Manager
- Employee
